# FlyBrain Pet — Motor System

## Principle (spec #15, #17, #18, #20, #21)

Movement is **not** brain→animation. It is:

```
brain → motor output → muscles/body dynamics → body motion
      → proprioception → nervous system
```

## Body model (spec #18)

Articulated skeleton:

- head (with eyes, antennae, proboscis)
- thorax
- abdomen
- 6 legs (3 pairs), each with joints: angle, velocity, torque, limits, inertia, damping
- 2 wings (stroke freq/amplitude, L/R asymmetry)
- 2 halteres (inertial feedback — rotation detection, flight stabilization)
- head/neck, proboscis, antennae DOFs

## Motor populations (spec #17)

Motor neurons from connectome (VNC leg neuropils, wing/haltere neuropils,
SEZ proboscis/neck circuits). Where exact muscle-level mapping is unavailable,
a documented **biomechanical approximation** is used — never labeled "exact
biological muscle wiring".

## Locomotion (spec #20)

Six-legged gait is generated by neural pattern generators driven by
connectome output, then fine-tuned by proprioceptive feedback. Animation, if
used, is only a visual interpolation layer over the physical result.

## Flight (spec #19)

- Wing stroke: frequency, amplitude, L/R asymmetry, thrust/lift reduced-order model
- Body pitch/yaw/roll, takeoff/landing/hover approximation
- Haltere feedback loop for stability
- NOT CFD — biologically plausible control

## Grooming / feeding / escape (spec #21–#23)

All emerge from sensory → neural → motor loops: tactile/odor/gustatory input
modulates neural activity; competing motor programs produce the observed action.
A passive behavior classifier labels what happened **after the fact** (spec #44)
and is never used to drive the fly.
